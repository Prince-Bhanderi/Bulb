# 💡 Bulb On/Off

A simple project — click the switch and the bulb turns on/off. A click sound also plays.

## Features
- Bulb glows on/off on click
- Click sound effect
- Pure HTML, CSS, JS (no framework)

## Tech Stack
- HTML
- CSS
- JavaScript

## Folder Structure
```
project/
├── index.html
├── css/
│   └── style.css
└── click.mp3
```

## How to Run
1. Clone the repo:
   ```
   git clone <repo-url>
   ```
2. Go into the folder:
   ```
   cd project-folder
   ```
3. Open the `index.html` file in your browser — that's it.

## Usage
Click the bulb's switch → the light toggles on/off, and a click sound plays along with it.
